# Wasal Server — خادم الحسابات والمراسلة

خادم تطبيق وصال (WASAL) للحسابات والمراسلة الفورية على Android.
مبني على Node.js و Express و Socket.IO و SQLite (better-sqlite3) مع مصادقة JWT.

> ملاحظة: هذا المستودع (wasal-media-server) هو **خادم الحسابات والمراسلة** الفعلي
> رغم اسمه التاريخي. خادم الوسائط والمكالمات المنفصل موجود في مستودع wasal-server.

## الوظائف

- إنشاء حساب دون رقم هاتف أو بريد إلكتروني أو كلمة مرور.
- توليد **رمز وصال فريد من 15 خانة بالضبط** (حروف إنجليزية كبيرة وصغيرة + أرقام، مع حرف ورقم إلزاميًا على الأقل)، مع إعادة التوليد تلقائيًا عند التكرار.
- إدارة الملفات الشخصية (الاسم، الصورة، النبذة).
- المحادثات الخاصة وإرسال واستقبال الرسائل النصية والوسائط.
- مؤشرات الإرسال والتسليم والقراءة عبر Socket.IO.
- المصادقة باستخدام JWT: رمز وصول 15 دقيقة + رمز تجديد 30 يومًا مع تدوير الرموز.
- حماية من الطلبات المتكررة (rate limiting) على التسجيل والبحث والإرسال والرفع.
- رفع ملفات الوسائط مع التحقق من النوع والحجم.

## التقنيات

- Node.js 20+
- Express
- Socket.IO
- SQLite (better-sqlite3)
- JWT (jsonwebtoken)
- Multer
- CORS

## متغيرات البيئة

| المتغير | الافتراضي | الوصف |
|---|---|---|
| `PORT` | 3000 | منفذ الخادم |
| `JWT_SECRET` | مطلوب | مفتاح توقيع الرموز (إلزامي، يتوقف الخادم بدونه) |
| `CORS_ORIGIN` | `*` | مصادر CORS المسموح بها |
| `DATA_DIR` | `./data` | مجلد قاعدة البيانات (يوجَّه إلى Volume دائم في الاستضافة) |
| `MEDIA_DIR` | `./media` | مجلد الملفات المرفوعة |
| `MEDIA_ALLOWED_HOSTS` | مضيفا خوادم وصال على Railway | المضيفات المسموح بها في روابط الوسائط |

## واجهات المصادقة

- `POST /api/auth/register` — إنشاء حساب جديد (يعمل أيضًا عبر `POST /api/users/create`)
- `POST /api/auth/refresh` — تجديد رمز الوصول
- `POST /api/auth/logout` — تسجيل الخروج من الجلسة الحالية
- `POST /api/auth/logout-all` — تسجيل الخروج من جميع الجلسات

## واجهات المستخدمين

- `GET /api/users/me` — بيانات المستخدم الحالي
- `PUT /api/users/me/display-name` — تعديل اسم العرض
- `GET /api/users/search/wasal-code` — البحث برمز وصال (15 خانة)
- `GET /api/users/:code` — الملف الشخصي لرمز معين

## واجهات المحادثات والرسائل

- `POST /api/conversations` — إنشاء محادثة أو فتحها
- `GET /api/conversations` — قائمة المحادثات (يعمل أيضًا عبر `GET /api/chats`)
- `GET /api/conversations/:code/messages` — رسائل محادثة
- `GET /api/messages/conversation/:conversationId` — رسائل محادثة بالمعرف
- `POST /api/messages` — إرسال رسالة
- `POST /api/messages/media` — إرسال رسالة وسائط
- `POST /api/messages/link` — إرسال رابط

## رفع الوسائط

```
POST /api/media/upload
```

- الحد الأقصى لحجم الملف: 100 MB
- يتحقق الخادم من التوقيع الفعلي للملف (magic bytes) وليس نوع MIME فقط.
- إعادة رفع الملف نفسه تعيد نفس الاسم بدل تكراره.

## سجل المكالمات

- `GET /api/calls` — سجل المكالمات للمستخدم الحالي.

## المراسلة الفورية

يستخدم الخادم Socket.IO لإرسال الرسائل وتحديث المؤشرات والحضور في الوقت الفعلي،
مع دعم تعدد الاتصالات لنفس المستخدم (أكثر من جهاز) ومهلات Ping مناسبة للشبكات الضعيفة.

## المصادقة

يستخدم الخادم JWT لحماية حسابات المستخدمين وعمليات المراسلة ورفع الوسائط،
مع تخزين بصمة رمز التجديد للسماح بإبطال الجلسات عند تسجيل الخروج.

## ملاحظة

البريد الإلكتروني ليس مطلوبًا لإنشاء الحساب العادي،
ويُستخدم لاحقًا كخيار اختياري للنسخ الاحتياطي واسترداد الحساب.
